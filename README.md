# Stock Price Movement Prediction (ML)

Educational research project that classifies **next-day stock price direction** (up vs down) from historical daily OHLC data using technical features and a Random Forest classifier.

This is **direction classification**, not price-level forecasting. It is **not** financial advice and must not be used for investment decisions.

> **Disclaimer:** This project is for educational and research purposes only. It is not financial advice and should not be used to make investment decisions.

## Dataset

| Field | Value |
|-------|-------|
| Source | Kaggle [`satyajeetbedi/stock-price-dataset`](https://www.kaggle.com/datasets/satyajeetbedi/stock-price-dataset) |
| Series | `CBX` (MIC `XZAG`, Zagreb Stock Exchange; ISIN `HRZB00ICBEX6`) |
| Date range | 2010-01-04 → 2015-12-30 |
| Target | `1` if next trading day's `last_value` > today's `last_value`, else `0` |

## Results (calculated on chronological test set)

Reproduced with `random_state=42`, Random Forest `n_estimators=200`, test fraction `0.2`  
(test period: 2014-10-29 → 2015-12-29, **n = 290**).

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|-------|----------|-----------|--------|-----|---------|
| Majority class (predict Down) | 0.541 | 0.000* | 0.000* | 0.000* | — |
| Logistic regression | 0.507 | 0.469 | 0.564 | 0.512 | 0.516 |
| Random Forest (primary) | 0.486 | 0.453 | 0.586 | 0.511 | 0.526 |

\*Precision / recall / F1 above are for the positive class (`Up`). The majority baseline always predicts `Down`, so positive-class scores are 0 while overall accuracy is 0.541.

**Interpretation:** On this dataset and feature set, the Random Forest does **not** outperform a majority-class baseline on accuracy. Results are consistent with weak short-term directional signal and should not be framed as reliable market prediction.

## Methods (summary)

1. Sort prices chronologically; drop incomplete OHLC rows.
2. Engineer trailing MA10 / MA50 and daily return (no future peeking).
3. Build next-day direction target; drop warm-up and final unlabeled row.
4. Chronological train/test split (`shuffle=False`).
5. Fit Random Forest (+ logistic regression and majority baselines).
6. Report classification metrics, confusion matrix, feature importance, and rolling directional accuracy.

## Limitations

- Market noise and weak predictability of daily direction
- Non-stationarity across market regimes
- Transaction costs / slippage not modeled
- Mild class imbalance
- Overfitting risk for tree ensembles
- Leakage risk if new features are added carelessly (mitigated here via chronological splits and trailing windows)
- No causal interpretation of feature importance
- Past performance does not guarantee future performance
